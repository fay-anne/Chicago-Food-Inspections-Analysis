# Raw Dataset – Chicago Food Inspections

This folder contains the original Chicago Food Inspections dataset used for the project.

**Source:** [Chicago Food Inspections – Kaggle](https://www.kaggle.com/datasets/chicago/chicago-food-inspections)

**Dataset details:**
- Original records: 196,825
- Original columns: 22
- Format: CSV (compressed as `.7z`)
- Period analysed: 2010–2019

**Data status:** Original, uncleaned dataset.

The dataset is preserved for reproducibility and comparison with the cleaned version. Data cleaning and preparation are documented in the project's Jupyter Notebook.
