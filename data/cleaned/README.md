# Cleaned Dataset – Chicago Food Inspections

This folder contains the cleaned dataset used for the Python analysis and Power BI dashboard.

**Dataset details:**
- Original records: 196,825
- Cleaned records: 196,676
- Columns after cleaning: 16
- Period analysed: 2010–2019
- Format: CSV (compressed as `.7z`)

**Data preparation:**
- Removed 149 duplicate records.
- Removed five completely empty columns.
- Removed the redundant `Location` column.

**Purpose:** This dataset was used for exploratory data analysis and to build the interactive Power BI dashboard.

The complete cleaning process, Python code, and analysis are documented in the project's Jupyter Notebook.
