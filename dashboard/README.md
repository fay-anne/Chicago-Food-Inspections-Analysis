# Chicago Food Inspections | Power BI Dashboard

## Overview
This folder contains the interactive Power BI dashboard developed to analyse Chicago food inspection results from 2010–2019.

The dashboard provides an overview of inspection outcomes, failure patterns, facility performance, common violations, and geographic distribution.

## Dashboard Features
- **KPI Cards:** Total inspections, completed inspections, failed inspections, and failure rate.
- **Inspection Outcomes:** Doughnut chart showing inspection results.
- **Failure Rate Trend:** Changes in inspection failure rates over time.
- **Facility Analysis:** Top five facility types by failed inspections.
- **Violations:** Five most frequently recorded violations.
- **Geographic Analysis:** Chicago ZIP-code-level inspection patterns.
- **Interactive Filters:** Year, facility type, risk category, and inspection result.

## Key Metrics
- **Total Inspections:** 196,676
- **Completed Inspections:** 171,470
- **Failed Inspections:** 38,055
- **Overall Failure Rate:** 22.19%

## Files
- **Power BI Report (`.pbix`):** Editable dashboard containing the data model, DAX measures, and visualisations.
- **Dashboard Screenshot (`.png`):** Preview of the completed dashboard.

## Usage
Download the `.pbix` file and open it using Power BI Desktop to explore the dashboard and interact with its filters.
